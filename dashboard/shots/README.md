# Le cinque pagine, catturate

Catture della dashboard accettata, in tema scuro, tutte dalla stessa
registrazione (`dashboard/demo/registrato/`) e quindi dagli stessi numeri.

| File | Pagina | Cosa mostra |
|---|---|---|
| `01-macchina.jpg` | MACCHINA | stato, OEE del giorno, ripartizione del tempo, le nove valvole in allarme |
| `02-valvole.jpg` | VALVOLE | la giostra: 35 valvole in pianta, ciascuna contro la propria banda |
| `03-oee.jpg` | OEE | la cascata del tempo, e le tre componenti con il loro riferimento |
| `04-tempo.jpg` | TEMPO | l'andamento a 14 giorni, le 35 sulla stessa scala, i due mesi |
| `05-carta.jpg` | CARTA | carta del ciclo singolo e della media di 46, con il verdetto per valvola |

Si rifanno aprendo le cinque pagine in modalita' demo:

    python dashboard/server_demo.py --port 8078

Prima di oggi non ne esisteva nessuna: le 284 catture in `.scratch/` sono
tutte della versione precedente, quella respinta.
